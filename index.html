Tentang studio

Dibangun dari workflow produksi, bukan kumpulan prompt acak.

OmniBoard menyusun prompt berdasarkan peran setiap sequence: membuka perhatian, memberi konteks, menampilkan produk, memperlihatkan detail, lalu menutup. Tujuannya sederhana—membantu kreator solo bergerak dari foto ke rencana produksi tanpa harus merancang struktur dari nol.

  • Bahasa antarmuka dan dialog dibuat untuk pengguna Indonesia.
  • Klaim produk tidak ditebak saat konteksnya tidak diberikan.
  • Prompt tetap perlu dijalankan di mesin video pilihanmu; studio ini menyiapkan tahap produksinya.

FAQ singkat

Yang biasanya ditanyakan sebelum mulai.

Apakah video langsung jadi di sini?

Belum. Studio menghasilkan prompt per sequence. Jalankan prompt tersebut di Google Flow/Veo, Seedance, Sora, Kling, Grok Imagine, atau Luma.

Kenapa harus upload foto?

Foto dipakai sebagai referensi visual untuk talent dan produk. File hanya dipreview di perangkat; saat generate video, upload foto yang sama ke mesin video pilihanmu.

Bagaimana menjaga konsistensi di Google Flow?

Generate Sequence 01 dari foto referensi. Mulai Sequence 02 sampai terakhir, buka hasil sebelumnya lewat fitur Edit lalu tempel prompt berikutnya.

Apakah Podcast Style mendukung dua talent?

Ya. Saat format Podcast Style dipilih, slot Talent 2 muncul otomatis dan prompt memisahkan identitas Talent A, Talent B, serta produk.

Bisakah hasilnya dibuat ulang agar tidak monoton?

Bisa. Tombol “Buat versi lain” meracik kombinasi kamera, blocking, ritme, transisi, dan dialog baru sambil mempertahankan aturan referensi.

Siap produksi?

Berhenti menebak prompt. Mulai dari referensi yang jelas.
